# shared-buddy

Swift package shared by Clipboard Buddy, Screenshot Buddy, and OTP Buddy.

## Modules

- **BuddyCore** — tagging, OTP detection, models, Keychain
- **BuddyUI** — SwiftUI primitives
- **BuddyFirebase** — analytics façade (no PII)
- **BuddyLocalization** — locales + string catalog
- **BuddyTesting** — fixtures

## Develop

```bash
swift test
```

Min macOS 13.
