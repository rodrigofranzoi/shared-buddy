# Screenshots — shared-buddy

N/A for the library. Apps follow this convention:

```
docs/screenshots/{locale}/
  raw/       # clean UI captures per feature
  banners/   # framed image + title + description
```

## Banner template

- Size: 1280×800 (Mac App Store friendly)
- Layout: app UI on left/center; title + one-line description on the side or below
- No floating promo stickers on the UI chrome
- One feature per banner

## Required feature shots (per app)

See each app’s `SCREENSHOTS.md`.
