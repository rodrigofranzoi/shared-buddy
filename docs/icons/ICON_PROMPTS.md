# Buddy Icon Concepts — Prompt Pack

Shared mascot + per-app icon prompts for Screenshot Buddy, Clipboard Buddy, OTP Buddy, and Paint Buddy.

## Shared character bible (use in every prompt)

**Name:** Buddy  
**Species:** Friendly cartoon dog (utility mascot for the macOS *-buddy suite)

**Look:**
- Soft golden-cream / warm apricot fur
- Big amiable eyes, gentle smile, rounded snout
- Small floppy ears, compact chubby-cute proportions
- Funky, playful, approachable — never scary, never corporate-stiff
- Feels like a helpful macOS sidekick, not a children’s toy brand

**Art direction (all icons):**
- macOS App Store icon quality, 1:1
- Polished flat / soft-vector illustration
- Soft lighting, clean shapes, high-contrast silhouette
- Readable at 32–64 px
- No text, letters, watermarks, or UI chrome
- Full-bleed square (no rounded corners / no radii on the icon canvas)
- Centered composition (dog slightly oversized)
- Same dog design across the suite — only props + background color change

## Screenshot Buddy

**Role:** Dog handling images / screenshot frames  
**Background:** Orange gradient (sunset orange → amber → soft peach)

### Prompt

```text
macOS app icon, 1:1, App Store quality. Funky amiable cartoon dog mascot named Buddy: soft golden-cream fur, big friendly eyes, gentle smile, rounded snout, small floppy ears, playful warm personality, chubby-cute compact proportions. Buddy happily handles floating screenshot image frames / glossy photo thumbnail cards (2–3 picture cards with abstract UI/window content). Soft orange gradient background from sunset orange to amber to peach. Polished flat-illustration style, clean vector-like shapes, soft lighting, high-contrast silhouette readable at small sizes. No text, no letters, no logos, no watermark. Full-bleed square canvas with sharp corners — no rounded corners, no radii, no squircle mask.
```

### Negative / avoid

```text
rounded corners, corner radius, squircle, iOS icon mask, realistic photo, scary dog, aggressive teeth, cluttered UI screenshots with readable text, purple glow, dark cyberpunk, watermark, app name text, multiple dogs
```

## Clipboard Buddy

**Role:** Dog holding sheet papers with post-its + fake text lines  
**Background:** Green gradient (mint → emerald → soft lime)

### Prompt

```text
macOS app icon, 1:1, App Store quality. Same funky amiable cartoon dog mascot Buddy from the *-buddy suite: soft golden-cream fur, big friendly eyes, gentle smile, rounded snout, small floppy ears, playful warm personality, chubby-cute compact proportions. Buddy happily holds loose white sheet papers / stacked paper sheets only — no clipboard board, no wooden clipboard, no metal clip. Sheets are not blank: each page has soft fake text lines (horizontal gray scribble / placeholder note lines that suggest writing but are NOT readable letters, words, or numbers). Also include a few colorful post-it sticky notes (yellow, pink, pale blue) stuck on some sheets and floating nearby, each with tiny fake scribble lines. Soft green gradient background from mint to emerald to lime. Polished flat-illustration style, clean vector-like shapes, soft lighting, high-contrast silhouette readable at small sizes. No readable text, no logos, no watermark. Full-bleed square canvas with sharp corners — no rounded corners, no radii, no squircle mask. Match the Screenshot Buddy dog character exactly.
```

### Negative / avoid

```text
rounded corners, corner radius, squircle, iOS icon mask, clipboard board, wooden clipboard, metal clip, binder, realistic photo, messy trash papers, office realism, scary dog, readable writing / real letters / words / numbers on pages, purple glow, watermark, app name text, different dog breed than Screenshot Buddy
```

## Consistency checklist (when regenerating)

1. Same dog face, fur color, ear shape, body proportions across all icons
2. Only swap prop set + gradient hue (+ beret for Paint Buddy)
3. Keep Buddy’s expression warm and helpful
4. Prefer one clear prop story per icon (images / sheet papers + post-its / lock / paint brush + beret)
5. Export final icons as opaque 1024×1024 PNG for macOS asset catalogs
