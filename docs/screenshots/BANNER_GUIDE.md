# Banner composition guide

For each required feature in SCREENSHOTS.md:

1. Capture a clean window or menu-bar popover into `raw/`.
2. Compose a 1280×800 banner in `banners/` with:
   - Feature title (localized)
   - One short description line
   - The raw UI as the dominant visual (no floating stickers)

Suggested tools: Figma, Sketch, or `sips` + a simple template.
